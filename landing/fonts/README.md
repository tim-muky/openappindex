# Fonts

Self-hosted since 2026-10-14, so no visitor's browser contacts Google. All three families are
licensed under the SIL Open Font License 1.1; the licence texts are in this folder.

| Family | Licence | Source |
|---|---|---|
| Fraunces | OFL-fraunces.txt | github.com/undercasetype/Fraunces |
| Schibsted Grotesk | OFL-schibstedgrotesk.txt | github.com/schibsted/schibsted-grotesk |
| Geist Mono | OFL-geistmono.txt | github.com/vercel/geist-font |

The woff2 files are the Latin and Latin Extended subsets as served by Google Fonts on 2026-10-10;
`fonts.css` declares them.
